## 🇨🇳 中文

逐镜分析已有视频，产出可追溯的镜头数据、真实参考帧、同步拉片 MP4 和简明画布摘要。它只沿用你选定的原片、范围、语言和交付目标，不生成也不复刻画面。每条镜头都有测量与复核依据，标注建立在证据上，不是凭感觉拆分。MP4 导出并验收后，会通过选项卡询问是否追加制作交互 HTML 报告；只有你明确选择需要时才做，未选择不算缺失交付项。

### ✨ 能做什么

- 输入已有成片 → 输出逐镜表 + 真实参考帧 + 画布摘要
- 测量并复核每个镜头的切点与时长，依据证据逐镜标注
- 导出分镜信息同步的学习 MP4，不做无关剪辑
- MP4 交付后可选追加交互 HTML 报告：点镜跳转、当前镜高亮
- HTML 报告的自动跟随滚动只在镜头列表容器内进行，带跟随开关
- 缺运行或预览条件时，明确报出哪些实现未完成，不把纯文字当成交互报告

## 🇬🇧 English

Shot-by-shot analysis of an existing video: it produces traceable shot data, real reference frames, a synchronized study MP4 and a concise canvas summary. It works only with the source clip, scope, language and delivery target you choose, and never generates or recreates imagery. Every shot is measured and re-checked before it is annotated, so labels rest on evidence rather than guesswork. After the MP4 is exported and accepted, a choice card asks whether to build the interactive HTML report; it is made only when you explicitly ask for it and is not a missing deliverable otherwise.

### ✨ What it does

- Existing film in, per-shot table plus real reference frames and a canvas summary out
- Each cut's timing measured and double-checked before evidence-based annotation
- Exports a storyboard-synced study MP4 with no unrelated edits
- Optional interactive HTML report after MP4 delivery: click a row to seek, current shot highlighted
- Auto-follow scrolling stays inside the shot-list container and can be toggled off
- If preview tooling is unavailable, it names what is unfinished instead of passing text off as an interactive report
